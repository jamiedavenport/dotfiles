# Browser baseline

Primary browser: Firefox

## Sync

Enable sync for:

- bookmarks
- settings
- extensions

Choose deliberately whether to sync:

- history
- open tabs
- passwords

## Appearance

- Follow system light/dark appearance.
- Avoid custom UI CSS unless there is a real usability problem.
- Prefer a built-in or account-synced theme.

## Extensions

Keep the list small.

Suggested categories:

- password manager
- content blocker
- development-specific extension only when required
